# Format breakdown — v1 (script + packaging measured; visuals/audio pending)

Evidence: `agents/packaging-analyst/report.md` (221 thumbnails, 5 channels) and
`agents/script-analyst/report.md` (22 word-timed transcripts). Both reviewed by lead.
v0 (thumbnail-only guesses) is superseded; hypotheses it got wrong are noted below.

## 1. The one rule above all
**Topic decides the outcome; execution is the floor.** Identical script quality produced 196K (hydrants) and 1.3K (utility marking).
Choose systems that (a) rank people/power, (b) decide life/death/danger, (c) are secret/restricted,
or (d) are a physical object everyone sees but misreads. Members must differ at a glance by colour or by a ladder step.

## 2. Packaging
- **Title:** `Every <Thing> (Color) Explained` or `How <System> Actually Works`. 4–7 words, US-centric. No numbers/emoji/colon. No sequels, no remakes.
- **Thumbnail:** 1280×720, white background, 6–20 isolated objects of one family (same scale/angle), 1–3-word label each,
  plus **one enlarged red-bordered anchor tile on the right with a red stamp stating a surprising fact** (NEVER AWARDED / NOBODY / NEVER USED).
  Red used nowhere else. No headline text, no scenes, no faces.
- **House style candidates:** Scrawl-style ink outline + flat fill + handwritten italic labels (Casual Tactics), or clean semi-real vector.
  Both can be drawn 100% in code (SVG).

## 3. Script (measured)
- **Hook:** 15–25 s cold open built from the *last, strangest item* = the thumbnail's red tile.
  Dated anomaly → contradiction → "there are N…" → open loop. First item by 0:25. No channel intro, first word ≤1 s.
- **Order:** declared escalation (low→high, common→rare, default→strangest). Last item = system-breaker, pays off the cold open.
- **Per item:** LABEL. → GIST (≤8 w) → MECHANISM + a hard number → SPECIFICS → TWIST ("But…") → dated STORY → BUTTON (≤14 w).
  Hard cut to the next label; no "next up".
- **Pacing:** 155–165 wpm, ~13 words/sentence, 8–12 min, ≥8 items; 20–60 s per item depending on count.
- **Mid CTA:** 45–55%, between items, ≤6 s. **Outro:** reframe + ≤8 s self-placing question ("What color are the hydrants on your street?").
- **Voice:** formal-neutral, present tense; irony only through facts; zero filler. Upload our script as manual captions.

## 4. What v0 got wrong
- "Red ? box" is weak (1.25×); the *stamp with a fact* is what works.
- Length doesn't hurt: winners run 8–14 min.
- Order is not "grid order" — it is a declared escalation, strangest last.
