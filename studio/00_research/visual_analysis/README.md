## The formula (all five agree)
1. **A new visual event every 2–3.5 s.** Never a static frame >3–4 s. Events = text line, label, pop-in, highlight box, counter, cut.
2. **Persistent HUD**: top-left topic/chapter (`01 / 11 · NAME · category`), top-right step counter (`STEP 3 / 12`), optional bottom progress ladder.
3. **Chapter loop**: grid/ladder re-anchor → push-in → title card (object left, huge title right, red kicker) → text slides that *mirror the narration* (red key phrase, bold black) → real-world evidence (photo/footage framed with a tag label) → data (comparison boxes, maps, bars, counters) → one-line takeaway → back to grid.
4. **Typography carries the story**: big headline text on almost every beat. Red = emphasis only.
5. **Camera**: grid push-ins between items (all); Casual Tactics uses one huge canvas with continuous pans/zooms and a hopping avatar ("YOU").
6. **Audio**: male, General American, 140–160 wpm, calm authority. Music = light lo-fi / minimal electronic beat, steady, −20…−24 dB under VO. SFX = soft UI clicks/pops on every entry, whooshes on moves, pencil scribbles on write-ons, stamp thuds on verdicts, coin clinks on money, ticking on quiz timers.
7. **Retention**: progress counter, mystery item teased at 0:00 and resolved last, myth-busting, 3-second quiz countdowns, comparisons (A vs B cards), outro question.
