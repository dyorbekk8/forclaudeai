Almost every American bomb and shell is olive drab — and that color means almost nothing. The real message is the stripe. Every color in the U.S. military ammunition color code (MIL-STD-709), from the yellow band on a live Mk 82 to the broken green band that marks a binary nerve agent.

CHAPTERS

3:47 Black: armor defeating
4:10 Gray: chemical
5:13 The whole code

Simplified for explanation; based on public U.S. military standards and manuals listed below. Colors fade and other countries use different codes — never treat any found ordnance as safe. If you find something, leave it and call 911.
