# Channel production rules (approved working defaults)

Source: `00_research/dossier/EXPLAINER_RESEARCH_DOSSIER_v2.md` (GPT research, 2026-11-04) + our own render/QA experience.
Positioning (hypothesis to test, not fact): **real-world systems decoded — colors, levels, signals, roles, equipment.**

## LOCKED channel direction (owner decision, 2026-11-05)
- Lane: **military, security & operations systems** (codes, levels, markings, roles, equipment). Next 15 videos stay in this lane.
- No new medical / brain / body / random-facts videos.
- Long videos 8–12 min (length from real facts and events, never padding).
- Every long video ships with 2–3 Shorts that link to it (related video).
- Thumbnails: own identity — one huge object + one curiosity line (B style); grid only as a test variant.
- Topics chosen by search demand where current top results are old/weak.
- One voice for everything: see `03_voiceover/VOICE.md`.

## Topic
- Score: familiar object · real question/misconception · primary source · visual mechanism · continuity with past uploads · original angle (0–4 each).
- Tag demand honestly: direct single-channel / cross-channel analogue / own-channel early / untested. No invented search-volume numbers.
- "Every X" only for a **bounded, complete set**. Otherwise "What X Actually Mean" / "U.S." / "Common". Never invent items to reach 8.
- Next cluster: aviation & operations (airport signs → runway markings → flight-deck jobs) before adjacent tests.

## Script
- No intro / logo. First useful distinction in the first sentences; title promise delivered in the first 30 s.
- Item length follows complexity, not a timer. Each chapter opens one small question and closes it.
- Every sentence has a job: definition · mechanism · example · consequence · contrast · exception · bridge.
- Claim ledger per video (exact claim, scope, source, caveat). Watch "always / never / only / every".
- No harmful detail (assembly, misuse, bypass). No sensationalised deaths.

## Voice
- One locked voice identity, model and settings for the whole channel (to confirm: the approved "Adam").
- Generate per sentence; Whisper check every sentence; regenerate mismatches. Pauses: . ≈0.4 s, : ≈0.3 s, line 0.3 s, section 0.6 s.
- Lock animation to the real recorded timing.

## Visual
- Light/cream background, clean contours, consistent semantic colors, original vector assets. Photos only where truly needed, licensed (PD / CC with credit).
- Motion has a job (draw, highlight, scale-in, move, compare, cutaway, grid reassembly). No dead holds > 4 s.
- No full-frame animated grain (hurts sharpness/bitrate). Burned-in narration subtitles OFF; .srt delivered separately.

## Audio
- SFX tied to on-screen events (cue sheet), varied, never masking speech. One continuous music bed under voice. −14 LUFS / ≤ −1 dBTP.

## Packaging
- Thumbnail families: A clean catalogue · B focused catalogue (one anchor tile) · C contrast. Check at 160–200 px. No fake "classified" stamps; a stamp must state a true fact.
- Use YouTube Test & Compare when eligible; otherwise change one variable at a time and read the same traffic source/period.

## QA
- 15–30 s representative proof before a full render. One render per output at a time.
- Metadata PASS is not enough: inspect frames and listen to joins, numbers, negations and the final CTA.
